# 대회 사이트 (suikagameweb.com)

대회: 11/9(월)~11/13(금), `https://suikagameweb.com/game/suikagame-ko.html`에서 둔 판의 결과 화면 캡처 제출. 최고점 1판으로 순위, 같으면 추첨. AI 참가 가능.

10-31 새벽에 내장 브라우저로 페이지 안의 게임 코드(`/game/public/src/project.js`)를 읽어 확인한 내용입니다. 우리 엔진(playsuikagame.com)과는 엔진도 규칙도 다릅니다.

## 규칙 (코드 기준)

- **나오는 과일**: 처음 6개는 0, 0, 1, 2, 2, 3으로 고정. 그 뒤로는 `RandomInteger(0, 5)`, 즉 0~5번 6종 균등(`window.difficulty = [0, 5]`). `Math.random` 사용. 다음 과일은 화면 왼쪽 위 NEXT에 표시.
- **떨어뜨리기**: 터치를 떼면 과일을 Dynamic으로 바꾸고 아래로 800 px/s 속도를 줌. 0.5초 뒤 다음 과일이 대기 위치에 나타남.
- **합체**: 같은 번호끼리 닿으면, 위에 있는 쪽이 0.1초 동안 아래쪽 위치로 끌려간 뒤 두 과일이 사라지고 아래쪽 위치에 다음 번호가 생김. 새 과일은 0.5초 동안 크기가 0에서 커지는 동안 Static이고, 그 뒤 Dynamic이 됨. 생길 때 아래로 100 px/s.
- **수박(10번)끼리는 합쳐지지 않음.** playsuikagame.com처럼 수박 두 개가 사라지는 일이 없어서, 판은 언젠가 반드시 찹니다.
- **점수**: 합체할 때마다 `번호 + 1` (체리 둘 = 1점, 멜론 둘 = 10점). 수박을 만들면 연출이 끝난 뒤 +100. 게임이 끝나면 통에 남은 과일마다 `번호 + 1`을 더함.
- **게임오버**: 과일의 위쪽 끝이 점선(`lineNode` 첫 자식)보다 위에 있고, 그 과일이 합체에 쓰인 적이 없고, 다른 과일과 닿은 적이 있고, 통에 들어온 지 3초가 지났으면 끝.

## 우리 엔진과 AI에 미치는 영향

- 물리 엔진이 달라서 지금 엔진으로는 탐색이 실제와 다른 판을 봅니다. Box2D 기반 엔진을 새로 만들어야 합니다.
- 수박끼리 사라지지 않으니 "수박 두 개 합치기 주기"(3만 점 계획)는 이 게임에 없습니다. 대신 통이 찰 때까지 수박을 몇 개 만들고(개당 +100), 큰 과일을 얼마나 많이 남기느냐(끝날 때 보너스)가 점수를 정합니다.
- 물리가 화면 프레임 시간에 따라 진행돼서 같은 입력에도 결과가 매번 조금씩 다릅니다. 엔진은 정확한 재현보다 비슷한 결과를 목표로 하고, 실제 사이트에서는 매 수 판을 다시 읽어야 합니다.

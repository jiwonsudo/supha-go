## 규칙 (코드 기준)

- **나오는 과일**: 0, 0, 0, 1, 2, 2, 3으로 시작하고, 그 뒤로는 `RandomInteger(0, 5)` = `floor(random × 5)`, 즉 0~4번 5종 균등(`window.difficulty = [0, 5]`). `Math.random` 사용. 다음 과일은 화면 왼쪽 위 NEXT에 표시.
- **떨어뜨리기**: 터치를 떼면 과일을 Dynamic으로 바꾸고 아래로 800 px/s 속도를 줌. 0.5초 뒤 다음 과일이 대기 위치에 나타나 0.5초 동안 커지고, 다 커져야 둘 수 있음. 한 수에 1초.
- **합체**: 같은 번호끼리 닿으면 위에 있는 쪽이 처리합니다. 두 과일의 충돌 반지름을 0으로 만들고, 위쪽 과일을 0.1초 동안 아래쪽 위치로 끌고 간 뒤 둘을 없애고 아래쪽 위치에 다음 번호를 만듭니다. 새 과일은 Dynamic이고 아래로 100 px/s로 시작하며, 0.5초 동안 크기가 0에서 커집니다(backOut, 최대 약 1.1배까지 넘쳤다가 1로). 크기가 바뀔 때마다 충돌 원도 다시 만들어집니다.
- **수박 만들기(9+9)**: 연출이 약 3초 동안 이어지고 그동안 과일을 둘 수 없습니다. 끝나면 +100.
- **수박(10번)끼리는 합쳐지지 않음.** playsuikagame.com처럼 수박 두 개가 사라지는 일이 없어서, 판은 언젠가 반드시 찹니다.
- **점수**: 합체할 때마다 `번호 + 1` (체리 둘 = 1점, 멜론 둘 = 10점). 수박을 만들면 연출이 끝난 뒤 +100. 게임이 끝나면 통에 남은 과일마다 `번호 + 1`을 더함.
- **게임오버**: 과일의 위쪽 끝이 점선(`lineNode` 첫 자식)보다 위에 있고, 그 과일이 합체에 쓰인 적이 없고, 다른 과일과 닿은 적이 있고, 통에 들어온 지 3초가 지났으면 끝.

## 우리 엔진과 AI에 미치는 영향

- 물리 엔진이 달라서 지금 엔진으로는 탐색이 실제와 다른 판을 봅니다. Box2D 기반 엔진을 새로 만들어야 합니다.
- 수박끼리 사라지지 않으니 "수박 두 개 합치기 주기"(3만 점 계획)는 이 게임에 없습니다. 대신 통이 찰 때까지 수박을 몇 개 만들고(개당 +100), 큰 과일을 얼마나 많이 남기느냐(끝날 때 보너스)가 점수를 정합니다.
- 과일이 `Math.random`으로 나와서 같은 판을 다시 볼 수 없습니다. 실제 사이트에서는 매 수 판을 다시 읽어야 합니다.
- **통 높이가 창 모양에 따라 달라집니다.** 캔버스는 너비 720에 맞추고(fitWidth) 높이는 창 비율을 따릅니다. 점선과 대기 위치는 `winSize.height / 2 + offset`(점선 -680, 대기 -580)이라, 세로로 긴 창일수록 바닥(y -528)에서 점선까지가 높아집니다. winH 1262.5일 때 약 970px입니다. 실제로 둘 때 winH를 읽어 엔진에 넣어야 합니다.

## 엔진 (`engine2/`)

- `engine2/vendor/box2d.js`: Cocos Creator 2.2.2의 `external/box2d/box2d.js` 그대로 (box2d.ts 2.3.2).
- `engine2/src/suika2.js`: 위 규칙을 옮긴 엔진. 좌표는 Cocos 월드 좌표(가운데 0, y 위쪽). 화면 주사율 `hz`, 창 높이 `winH`를 받음.
- `engine2/src/server.js`: 기존 `engine/src/server.js`와 같은 명령(new, turn, clone, evaluate 등). x는 상자 좌표(왼쪽 벽 0, 오른쪽 벽 720), 상태는 y 아래쪽 좌표.
- Python은 `SUPHAGO_ENGINE=2`로 이 엔진을 씁니다. 에이전트 코드는 그대로입니다.
- 판 복사는 물리 세계를 새로 만드는 방식입니다. Box2D 객체를 통째로 깊은 복사하면 수십 번 뒤 메모리가 폭주했습니다. 접촉 캐시가 빠져서 한 수 뒤 위치가 중앙값 0.5px, 최대 8px 다릅니다.
- 속도: 한 프레임 약 0.1ms. MC 2수 + 판 모양 한 수에 약 1.5초(컨테이너 한 코어).

**첫 시험** (컨테이너, 2판): MC 2수 + 판 모양 (1, 0.3) 1343점, 1868점, 평균 378수. 지원님 한 판 1250점.

**아직 안 한 것**: 실제 사이트 판과 비교 검증, 실제 사이트에서 두는 코드.
